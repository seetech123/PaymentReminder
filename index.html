Payment Reminder Follow-up Agent

Automated AI payment reminder system for small & medium businesses

This repository contains the full Streamlit Python application for scanning overdue invoices, drafting personalized AI emails via Groq LLM, and sending automated follow-ups via Gmail SMTP.

📊 Multi-Format Support

Upload invoices in Excel (.xlsx, .xls), CSV, PDF, or Word (.docx) format.

🧠 Groq AI Drafting

Generates professional, personalized follow-up reminder emails tailored to overdue days & invoice notes.

📧 Direct Gmail SMTP

Integrates securely with your Gmail App Password to dispatch follow-up emails directly.

🚀 How to Run Locally

pip install -r requirements.txt
streamlit run app.py
